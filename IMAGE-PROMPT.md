goal:
generate a 16:9 hero illustration that is visually consistent with my blog brand and clearly
specific to the exact post content below (not generic tech art).

process (important):

1. first, analyze the blog post and extract:
   - main topic
   - primary technical problem
   - key technologies/tools mentioned
   - one concrete outcome or takeaway
2. then design the image concept around those extracted points.
3. ensure a viewer can feel this image belongs to this exact post.

style system (must stay consistent for all posts):

- format: 16:9 landscape hero image, full-width display at 640px.
- visual style: modern editorial technical illustration, minimal, clean, high contrast.
- background base color: hsl(0, 9%, 7%) (dominant).
- surface color: hsl(0, 6%, 10%).
- borders and structural lines: hsl(0, 4%, 23%).
- primary contrast and light detail: hsl(0, 15%, 94%).
- muted secondary detail: hsl(0, 4%, 71%).
- accent color: #f86105 (sparingly, for focal points/highlights).
- mood: focused, professional, calm, future-facing.
- composition: one clear focal point, supported by three to five related visual elements and
  intentional negative space.
- add only the technical motifs needed to explain the post's idea; every element must have a
  purpose.
- use depth only when it helps explain the relationship between elements.
- keep a polished, cohesive “same series” look across all posts.

post-specific requirements (critical):

- avoid generic “random tech” visuals.
- include 2–4 concrete visual cues tied to this post’s exact subject (tools, architecture pattern,
  workflow steps, error context, or domain concept).
- if the post mentions a specific flow (e.g., request -> validate -> db -> response), reflect that
  flow visually.
- if the post is about optimization/debugging/migration/security/etc., make that action the visual
  story.
- prioritize conceptual clarity over decoration.

text in image:

- you may include a very small amount of text only if it improves post specificity.
- keep text minimal (max 3–6 words total), subtle, and integrated into the design.

- no big headline text, no paragraph text, no watermark.

- no unrelated icons/elements.
- no clutter or tiny unreadable ui.
- no logos unless explicitly mentioned in the post and necessary for context.
- do not break the brand palette consistency.
- no excessive glow, gradients, 3D surfaces, decorative particles, or floating elements without a
  clear connection to the post.

output:
produce one final hero illustration concept that is:

1. clearly tied to this specific blog post content,
2. consistent with the same brand style used across my other posts,
3. clean and readable at 640px full-width display.
